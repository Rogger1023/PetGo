Conheça o PetGo

Tecnologia, praticidade e carinho pelos pets. Uma experiência de compra feita para facilitar a vida de quem cuida dos seus animais.

Nossa proposta

O PetGo busca oferecer uma navegação simples e intuitiva, permitindo explorar categorias, conhecer produtos e realizar compras de forma organizada.

Como surgiu

O PetGo nasceu como um projeto acadêmico de desenvolvimento de software, com o objetivo de colocar em prática conceitos de programação, banco de dados, segurança e integração de sistemas.

Por trás da tecnologia

A aplicação utiliza PHP e Laravel no backend, JavaScript no frontend, MySQL para persistência de dados e Docker para organizar o ambiente.

Nosso compromisso

Criar uma aplicação funcional, acessível e agradável de utilizar, seguindo boas práticas de desenvolvimento e segurança.
